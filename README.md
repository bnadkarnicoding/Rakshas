# Rakshas

A story-and-exploration game set in a pristine, mythic world stretching from India to Japan, built on our own engine.

- **Design rules:** `CorePrinciples.md`, kept in the Rakshas Studio project.
- **Engine design:** [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## Current state: rung 6

You walk an **animated figure** (a wooden-mannequin placeholder that stands, walks and runs, blending smoothly with your speed) through a small village of thatched round huts, across a grassy meadow, into the woods and up a lookout ridge. The world is loaded from a content file. The **hybrid camera** changes its framing as you move, gliding with no cuts and no shake:

- **Explore:** follows behind you; you steer it.
- **Vista:** at the top of the lookout ridge, it pulls back to show the valley.
- **Duel:** near the dark figure west of the village, it goes tight over your shoulder.
- **Conversation:** next to the elder in the village, it frames you both side-on.

**Sound:**

- Footsteps land exactly in time with the stride, on dirt in the village and grass elsewhere.
- Wind rises in the open and on the ridge, and leaves rustle among trees.
- Birds call by day and insects sing at night.
- The world hushes as a duel framing takes hold.

Press **M** to mute.

The **detail preview** adds:

- textured ground and stone,
- huts loaded from a 3D model file (glTF, the format Blender exports),
- trees and grass that sway gently in the wind and cast shadows.

All art, animation and sound is **placeholder**, generated by the scripts in `tools/`. Final art, motion (motion capture or an animator) and sound (a sound designer or field recordings) come later.

### Replacing sounds

Sounds live in `content/sounds/`. Replace any `.wav` file with a real recording of the same name (mono or stereo, any sample rate) and the game uses it. Looping sounds (`wind_loop`, `leaves_loop`, `insects_loop`) should loop seamlessly.

In a zone you can still nudge the view, and it drifts back when you let go. Press **C** to switch to "fully directed" (look input ignored in zones) and compare.

### Changing the land yourself

The landscape and its placeholder objects live in a plain text file:

```
content/regions/rung2_forest_lake.rk
```

Open it in any text editor (Notepad works). You can:

- change a number,
- add a `hill`,
- move a `prop`,
- move the `player` start,
- add or move a `camera_zone` (framing: `vista`, `duel` or `conversation`),
- add a `forest` or `grass` area, or change its `seed` for a different arrangement,
- place a 3D model with `shape: model` and `model: models/<file>.gltf`.

### Adding your own 3D models

In Blender:

1. Choose **File → Export → glTF 2.0**.
2. Set the format to **glTF Separate (.gltf + .bin + textures)**.
3. Save into `content/models/`, with the images next to it or in `content/textures/`.

Use metres, with the model standing on the ground at its origin and its front facing +Y in Blender (+Z in the game).

**Animated characters:**

- Export the armature and mesh together, with animations named `idle`, `walk` and `run`.
- Use **Linear** interpolation.
- The character's front should face −Y in Blender (−Z in the game).
- One walk cycle should cover 2 m at 2 m/s, and one run cycle 3.3 m at 5 m/s, so the feet don't slide.

Replace `content/models/mannequin.gltf` to swap in a new figure.

Save, rebuild (`cmake --build --preset windows-release`), and run. If something in the file is wrong, the game tells you the line and suggests a fix, for example "did you mean 'position'?".

## Building on Windows

**One-time setup:**

1. Install **Visual Studio Community** (2022 or newer) with the **"Desktop development with C++"** workload. This includes CMake and Ninja.
2. Install **Git for Windows**.
3. Install the **Vulkan SDK** from LunarG (vulkan.lunarg.com). The defaults are fine. It provides the shader compiler and validation layers.

**Build and run:**

From the Start menu, open **"x64 Native Tools Command Prompt"** (installed with Visual Studio) and run:

```
git clone <your repository URL> rakshas
cd rakshas
cmake --preset windows
cmake --build --preset windows-release
build\windows\bin\rakshas.exe
```

## Building on Linux / Steam Deck

```
sudo apt install cmake ninja-build g++ libvulkan-dev glslc vulkan-validationlayers \
                 libx11-dev libxext-dev libwayland-dev libxkbcommon-dev
cmake --preset linux-debug
cmake --build --preset linux-debug
./build/linux-debug/bin/rakshas
```

## Automated checks

- `rk_tests` runs the unit tests.
- Headless render, with no window:

  ```
  rakshas --headless --validate --time 0.3 --out shot.png
  ```

  Add `--audio-out sound.wav` to record what you'd hear during a scripted walk, with `--listen <seconds>` to stand still and listen afterwards.

  Add `--low` to use the low graphics preset (smaller shadow map), or `--region <file>` for another region file:

  ```
  rakshas --low --region content/regions/rung2_forest_lake.rk
  ```

  The exit code is non-zero if any Vulkan validation error or engine error occurs.
- GitHub Actions (`.github/workflows/ci.yml`) builds on Windows and Linux. On Linux it also runs the tests and renders screenshots for every change.
